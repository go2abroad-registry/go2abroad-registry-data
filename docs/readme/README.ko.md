## 사용 방법

1. 아래 행렬에서 볼륨 저장소를 엽니다.
2. `batch-01` … `batch-05`(각 200개)를 탐색합니다.
3. 각 `{task_id}` 폴더에서 `index.html` / `index.{{lang}}.html`을 열거나 `data.jsonl` / `data.{{lang}}.jsonl`을 다운로드합니다.
4. 최신 정규 뷰는 공식 포털을 우선하세요.
