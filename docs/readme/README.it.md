## Come usare

1. Aprire un repository di volume dalla matrice sotto.
2. Sfogliare `batch-01` … `batch-05` (200 voci ciascuno).
3. In ogni cartella `{task_id}`: aprire `index.html` / `index.{{lang}}.html` o scaricare `data.jsonl` / `data.{{lang}}.jsonl`.
4. Preferire il portale ufficiale per la vista canonica aggiornata.
