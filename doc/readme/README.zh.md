## 🌐 项目简介
**GO2ABROAD Registry** 是一个完全开放的跨国商事实体与法定合规智能中枢，覆盖全球 **80+ 离岸与本土管辖区**。

基于 **23,795+ 份结构化商事档案**，完整解析企业出海设立与维系的 6 大法定阶段：
1. **尽调核名与实控人 (UBO) 穿透披露**
2. **法定设立流程与首期董事会决议范本**
3. **税号申领（EIN/VAT）与流转税规则**
4. **商业大行准入、EMI 白名单与风控防御**
5. **年审维系日历与强制财务审计门槛**
6. **企业所得税申报（CIT）与反避税合规红线**

## 📂 开放数据资产
* **目录索引 (`catalog_index.min.json`)**：全量高频字段紧凑索引，支持毫秒级检索与统计。
* **11 语种多语言字典 (`dimension_i18n.json`)**：实体形式、行业分类与商业模式的多语种映射。
* **合规全案底本 (`dossiers/*.jsonl`)**：深层展开的 6 阶段纯正法定档案。
